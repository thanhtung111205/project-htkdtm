# Nhập lại dashboard EduVision vào Superset

1. Nén **toàn bộ nội dung thư mục `dashboards/`** thành một file `.zip`. File nén cần chứa `metadata.yaml`, `charts/`, `dashboards/`, `datasets/` và `databases/`.
2. Mở Superset, truy cập **Dashboards** rồi chọn **Import Dashboards**.
3. Chọn file `.zip` vừa nén và xác nhận nhập dữ liệu.
4. Kiểm tra Dashboard 1–4 sau khi nhập.
